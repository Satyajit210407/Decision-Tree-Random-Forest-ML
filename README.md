# Decision Tree & Random Forest Classifier

## 📌 Project Overview
This project explores and compares two supervised machine learning classification algorithms: Decision Tree and Random Forest. The models are implemented using the Iris and Tips datasets.

## 🎯 Objectives
- Explore datasets using Pandas and Seaborn.
- Identify and encode categorical variables.
- Split data into training and testing sets.
- Train Decision Tree and Random Forest classifiers.
- Evaluate models using accuracy scores and classification reports.
- Compare the performance of all four dataset-model combinations.

## 📊 Datasets

### 1. Iris Dataset
- **Target:** `species`
- **Task:** Predict flower species from sepal and petal measurements.
- **Type:** Multiclass classification.

### 2. Tips Dataset
- **Target:** `time`
- **Task:** Predict whether a meal occurred during lunch or dinner using bill, tip, customer, and dining-related features.
- **Type:** Binary classification.
